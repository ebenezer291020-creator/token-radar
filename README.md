# Token Radar

AI-built token launch radar for the [make.fun token-radar-01 bounty](https://make.fun/bounty/token-radar-01) ($1,325 in USDC).
Scores every pre-token protocol in a sealed snapshot into one ranked board (198 rows: watchlist coverage + early finds),
with a dynamic dashboard and a full dossier.
